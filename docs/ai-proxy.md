# «Облако Лоли» — сервер-посредник AI

Пользователь входит в аккаунт Лоли, и она отвечает на любые вопросы через ваш сервер, без собственного API-ключа.
Ключ провайдера хранится только в секретах Supabase. У каждого пользователя есть дневной лимит запросов.

## Сколько стоит
- **Supabase:** бесплатного тарифа хватает (Edge Functions — до 500 000 вызовов в месяц).
- **Провайдер AI** оплачивается за запросы. Пример: DeepSeek через OpenRouter стоит примерно $0.3 за 1 млн входных токенов. Один вопрос — это 1–2 тыс. токенов, то есть 1000 вопросов ≈ 10–50 ₽.
- **Лимит** по умолчанию — 100 запросов на пользователя в сутки. Он защищает от злоупотреблений.

## Как включить (один раз)
1. Создайте проект на [supabase.com](https://supabase.com). В репозиторий должны быть добавлены переменная `SUPABASE_URL` и секрет `SUPABASE_ANON_KEY` — это уже нужно для входа и синхронизации.
2. Примените миграцию:
   ```bash
   supabase link --project-ref <ваш-проект>
   supabase db push
   ```
   Она создаёт таблицу `ai_usage` и функцию `ai_usage_take`.
3. Получите ключ провайдера. Например, на [openrouter.ai](https://openrouter.ai): пополните баланс на $5 → Keys → Create key.
4. Задайте секреты и разверните функцию:
   ```bash
   supabase secrets set LOLI_AI_KEY=sk-or-...
   # необязательно:
   supabase secrets set LOLI_AI_MODEL=deepseek/deepseek-chat LOLI_AI_DAILY_LIMIT=100
   # другой провайдер (любой OpenAI-совместимый):
   # supabase secrets set LOLI_AI_BASE_URL=https://api.deepseek.com/v1 LOLI_AI_MODEL=deepseek-chat
   supabase functions deploy ai-proxy
   ```
5. Соберите новую версию приложения (Actions → Release APK). После входа в аккаунт на главной появится «Облако Лоли».

## Безопасность
- **Кто может обращаться:** функция принимает только запросы вошедших пользователей — проверяется их токен Supabase.
- **Лимит запросов** считается атомарно в базе. Клиент не может изменить счётчик.
- **Ограничения запроса:** модель, `max_tokens` и размер запроса задаёт сервер, а не приложение.
- **Ошибки провайдера** отдаются без подробностей: ключ никогда не попадает к клиенту.
