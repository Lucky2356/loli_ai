# Лоли — персональный голосовой AI-ассистент для Android

Лоли — это ассистент в духе JARVIS. Вы говорите обычными фразами («Лоли, сегодня потратила 850 рублей на продукты», «добавь к идее холодильника сканирование штрихкодов», «напомни завтра в 10 утра позвонить клиенту»), а она сама понимает, что это: расход, идея, задача, напоминание или факт для памяти. Потом сохраняет данные в нужный раздел, находит существующие записи по смыслу и отвечает голосом.

Данные хранятся на устройстве (офлайн-режим, шифрование) и синхронизируются через Supabase. Архитектура заранее рассчитана на будущий Windows-клиент.

## Возможности

| Область | Что работает в текущей версии |
|---|---|
| **Локальное понимание речи (по умолчанию)** | Лоли понимает русскую речь прямо на телефоне — без интернета, AI и API-ключей. Свободные формулировки («закинула в продуктовый 850», «такси 380», «у меня завтра встреча в 15:00»), составные фразы («запиши расход 500 на такси и напомни завтра в 9 позвонить маме»), разговорные суммы («полтинник», «пятихатка», «косарь»), дозаполнение («Сколько потратили?» → «500»), мозговой штурм («давай придумаем приложение для склада» → «там нужно…» → «хватит»), план на день, отмена и исправление («отмени последнее», «не 850, а 950»), вопросы по памяти («как меня зовут?»), уточнения к расходам («а на транспорт?»), калькулятор, время и дата, поиск по смыслу через словарь синонимов. Нераспознанную фразу Лоли предложит сохранить заметкой. |
| **Облачный AI (необязательно)** | Можно подключить **сразу несколько провайдеров** (OpenAI, Gemini, Claude, OpenRouter, DeepSeek, Mistral, Groq, xAI, свой сервер) и расставить их по приоритету. Запрос идёт первому; при ошибке, лимите или отсутствии ключа — автоматически следующему; без сети команда выполняется на устройстве. Модель возвращает структурированные действия (JSON), приложение проверяет их перед выполнением. |
| **Заметки и идеи** | Создание, дополнение («добавь туда…», «добавь к идее про холодильник…»), поиск, редактирование и удаление. Существующая запись находится по смыслу, а не по точному названию. |
| **Уточнения** | Если под описание подходят несколько записей, Лоли спросит, какую изменить, и не станет менять случайную. Если подходящей нет, создаст новую. |
| **Расходы** | Сумма, валюта, автоматическая категория, дата («вчера»). Ответы на вопросы: «сколько я потратила в этом месяце / на продукты / вчера», «самые большие расходы», «расходы за неделю». Экран статистики с разбивкой по категориям. |
| **Задачи** | Создание со сроком («на завтра в 15:00»), отметка «выполнено», списки: на сегодня, просроченные, выполненные. |
| **Напоминания** | Разовые («завтра в 10», «через два часа») и повторяющиеся («каждый понедельник в 9», «по будням в 8:30»). Используются уведомления через AlarmManager и кнопки «Готово» / «Через 10 минут». Напоминания переживают перезагрузку. |
| **Память** | Факты о пользователе («запомни, что…») подставляются в контекст AI для персональных ответов. Лоли отвечает на вопрос «что ты обо мне знаешь». |
| **Контекст разговора** | Лоли понимает, к чему относятся «там», «туда», «ещё». История ограничена: 12 реплик, 8000 символов, 15 минут тишины. |
| **Диалоговый режим** | После любого ответа Лоли продолжает слушать без обращения по имени: можно давать команды одну за другой («…и добавь задачу», «ещё запиши расход»). Разговор заканчивается фразой «хватит» / «спасибо, всё» или двумя паузами подряд. «Давай подумаем над идеей» — мозговой штурм, где сказанное дописывается в идею. |
| **Подтверждения** | Удаление и отмена требуют явного «да» голосом или кнопкой. |
| **Поиск по смыслу** | Гибридный: основы слов (стеммер Snowball) + синонимы от AI + эмбеддинги (OpenAI, Gemini), если они доступны. |
| **Голос** | Распознавание: системное (Google) с автоматическим переключением на **встроенную офлайн-модель Vosk** (она уже в APK — скачивать не нужно), а в крайнем случае — на системное окно Google. Озвучка: системный синтезатор (TTS). Wake word «Лоли» в фоне. |
| **Ассистент по умолчанию** | Лоли можно выбрать «Цифровым ассистентом» Android: долгое нажатие «Домой»/питания открывает компактное окно Лоли поверх любого приложения. Также — плитка в шторке и ярлык. |
| **Команды телефону (офлайн)** | «Поставь таймер на 5 минут», «разбуди меня в 7:30 по будням», «открой телеграм», «позвони маме», «напиши Саше, что я задержусь», «включи фонарик», «сколько заряда», «следующий трек», «сделай погромче», «найди в интернете…», «построй маршрут до вокзала», «открой настройки Wi-Fi». Работает и при свёрнутом приложении (нужно разрешение «Поверх других приложений»). |
| **Ещё команды** | Камера и селфи, видео, сайты («открой сайт habr.com»), музыка по названию, YouTube, событие в календарь (сразу, если разрешён доступ к календарю), новый контакт, отправка текста в Telegram/WhatsApp/VK, «Не беспокоить», яркость, режим полёта, NFC, точка доступа. Через спецвозможности: «назад», «домой», «недавние», «открой уведомления», «сделай скриншот», «заблокируй экран», «меню питания». |
| **Экран блокировки** | Лоли работает без разблокировки: жест/кнопка питания (если выбрана ассистентом), кнопки громкости, слово «Лоли» в фоне. Результат — уведомлением. Что разрешено на блокировке, задаёт пользователь («Настройки → Доступ»): по умолчанию можно записывать новое, таймеры/будильники и звонки, а показывать и менять личные данные и открывать приложения — нельзя. |
| **Вызов кнопками** | Удержание «Громкость +», двойное «Громкость −» или обе кнопки громкости (через спецвозможности; обычная регулировка громкости сохраняется). |
| **Доступ к приложениям** | Лоли открывает только разрешённые приложения. Банки, платёжные, Госуслуги, криптокошельки и менеджеры паролей закрыты, пока пользователь сам их не разрешит. |
| **Защита** | Вход в приложение по отпечатку/лицу/PIN (повторно — после минуты в фоне); проверка SHA-256 каждого обновления; облачному AI на заблокированном экране не передаются память и записи. |
| **Полезное без интернета** | «Сколько дней до нового года», «какой день недели 8 марта», «переведи 5 миль в километры», «100 градусов по Фаренгейту в Цельсии», монетка, кубик, случайное число, калькулятор. |
| **Автообновление** | Лоли раз в 12 часов проверяет GitHub Releases, скачивает новую версию и ставит её через системный установщик (первый раз Android попросит подтверждение). Выключается в «Настройки → О приложении». |
| **Виджет** | «Спросить Лоли» на рабочем столе — одно касание открывает окно ассистента. |
| **«Стоп» всегда** | Слово «стоп» (а также «стой», «хватит», «замолчи») останавливает Лоли сразу: пока она слушает, думает или говорит. Во время ответа работает отдельный офлайн-распознаватель только слов остановки с эхоподавлением, поэтому собственный голос Лоли его не сбивает. |
| **Голос и цвет** | В настройках голоса можно выбрать любой русский голос установленного синтезатора, скорость и высоту. Больше голосов даёт другой синтезатор, например RHVoice. В «Оформлении» есть 10 цветов Лоли: индиго, зелёный, голубой, белый, фиолетовый, красный, розовый, жёлтый, оранжевый, бирюзовый. |
| **Чат** | На главной закреплены сфера, переходы в разделы и небольшое окно чата. Нажатие открывает чат на весь экран; переписка разбита по дням («Сегодня», «Вчера», дата), у сообщений есть время. |
| **Надёжный AI** | Ключ очищается от случайных пробелов и переносов. Кратковременные сбои повторяются. Если сервер не принимает параметр, уходит простой запрос. «Проверить подключение» делает тот же запрос, что и при работе. Если AI не ответил, под ответом видна причина, а последний сбой показан в настройках AI. |
| **Распознавание речи** | Можно выбрать паузу до конца фразы. Оборванную фразу («купи хлеб и…») Лоли дослушивает. Из нескольких вариантов распознавания выбирается тот, который Лоли понимает. Частые ошибки («Лали», «тыщ», «на помни») исправляются. Распознаватель получает подсказки: имя ассистента и слова команд. |
| **Безопасность** | Защита от инъекций: звонки, сообщения, отправку и открытие сайтов AI выполняет, только если об этом просили в самой фразе, а текст записей для AI — данные, а не команды. Обновление ставится только с GitHub и только после проверки контрольной суммы, имени пакета, подписи и версии. Данные не уходят в резервные копии и не переносятся на другой телефон. Есть настройка «Скрывать экран» (без скриншотов, записи экрана и показа в недавних). |
| **Минимум ручных действий** | На главной есть кнопка «Настроить всё». Лоли сама проходит шаги подряд: разрешения одним окном, ассистент, работа поверх приложений, спецвозможности, батарея, точные напоминания. После каждого системного экрана сразу открывается следующий, а с запущенным Shizuku почти всё включается без экранов. Разрешения на контакты и календарь спрашиваются прямо во время команды («позвони маме»), и команда выполняется сразу после согласия. Точные напоминания на Android 13+ не требуют настройки. После ввода AI-ключа Лоли сама проверяет подключение и выбирает доступную модель. Каждое утро приходит сводка задач и напоминаний на день. |
| **Списки покупок** | «Добавь в покупки молоко, хлеб и яйца», «что купить?», «купила молоко» (без суммы — вычёркивает из списка, с суммой — записывает расход), «убери купленное». Вкладка «Покупки» в «Планах» и виджет на рабочий стол. Синхронизируются, если на сервере применена миграция `20260927000000_lists_and_routines.sql`. |
| **Сценарии** | «Когда я говорю „спокойной ночи“ — поставь будильник на 7 и включи не беспокоить». Потом достаточно сказать «спокойной ночи». Шаблоны и удаление — в настройках ассистента. |
| **Диктовка** | «Надиктую заметку» — Лоли слушает с длинными паузами, пока не услышит «готово», и сохраняет текст заметкой. |
| **Дни рождения** | «День рождения мамы 5 мая», «когда день рождения у Саши?», «у кого дни рождения в этом месяце». Импорт из контактов одной кнопкой. Напоминание накануне вечером и в сам день. |
| **Секретные заметки** | Открываются только по отпечатку или PIN-коду, хранятся лишь в зашифрованной базе телефона: не синхронизируются, не попадают в поиск и в AI. |
| **Переводчик** | «Переведи на английский где вокзал», «как по-немецки спасибо». С AI — любой текст, без AI — частые фразы. Ответ произносится голосом нужного языка. |
| **Даты словами** | «2 дня назад», «неделю назад», «в прошлую пятницу», «на следующей неделе в среду», «через 3 недели», «через час двадцать». |
| **Голоса** | Выбор синтезатора речи (Google, Samsung, RHVoice…), голоса для скачивания и пять готовых стилей звучания — даже если в телефоне всего один голос. |
| **Разные телефоны** | Подсказки под Xiaomi, Samsung, Huawei, Oppo/Realme/Vivo, шаг «Автозапуск» там, где он нужен. Обязательных шагов настройки два, остальные — по желанию. Интерфейс подстраивается под маленькие экраны, крупный шрифт и планшеты. |
| **Интерфейс** | Минималистичный дизайн: светлая и тёмная темы, цвета обоев (Android 12+), вкладки «Лоли · Записи · Планы · Расходы · Настройки», редактирование в нижних панелях. |
| **Аккаунт** | Регистрация и вход по email и паролю (Supabase Auth), сброс пароля, режим «без аккаунта». |
| **Синхронизация** | Local-first. Очередь изменений, слияние конфликтов без потери текста, soft delete, фоновая синхронизация через WorkManager. |
| **История** | Все разговоры сохраняются и синхронизируются. |

## Архитектура

```text
┌────────────────────────────── app (Android) ──────────────────────────────┐
│ UI (Jetpack Compose): Главная · Память · Заметки · Идеи · Расходы ·        │
│   Задачи · Напоминания · История · Настройки · Вход                        │
│ Presentation: HomeViewModel, VoiceController (слушать → понять → ответить) │
│ Платформенные адаптеры:                                                     │
│   STT: AndroidSpeechRecognizerProvider, VoskSpeechProvider                  │
│   TTS: AndroidTtsProvider · Wake word: WakeWordService (FGS microphone)     │
│   Напоминания: AlarmReminderScheduler · Синхронизация: SyncWorker           │
│   Секреты: KeystoreSecretStore · БД: SQLCipher-драйвер                      │
└───────────────────────────────┬────────────────────────────────────────────┘
                                │ зависит только от интерфейсов ядра
┌───────────────────────────────▼──────────── core (Kotlin/JVM) ─────────────┐
│ Domain: модели, интерфейсы репозиториев, SpeechRecognitionProvider,        │
│         TextToSpeechProvider, ReminderScheduler                            │
│ Assistant: AssistantEngine → PromptBuilder → AIProvider → ActionParser     │
│            (валидация) → ActionExecutor → Outcome; LocalCommandParser      │
│            (офлайн); ConversationContext; TargetResolver                   │
│ AI: AIProvider / EmbeddingProvider; OpenAiCompatibleProvider (OpenAI,      │
│     Gemini, OpenRouter, локальные серверы), AnthropicProvider              │
│ NLP (ru): числа словами, даты/время, повторения, стеммер, категории,       │
│           wake word                                                        │
│ Data: SQLDelight (схема + репозитории) · Search: гибридный поиск           │
│ Sync: SyncEngine (pull → merge → push) · Remote: PostgREST, Supabase Auth  │
└───────────────────────────────┬────────────────────────────────────────────┘
                                │ HTTPS (PostgREST, GoTrue)
┌───────────────────────────────▼──────────────── Supabase ──────────────────┐
│ PostgreSQL: notes, expenses, tasks, reminders, memories,                   │
│ conversation_messages, profiles · RLS на всех таблицах ·                   │
│ триггер last-write-wins · Auth (email/пароль)                              │
└────────────────────────────────────────────────────────────────────────────┘
```

**Почему два модуля.** Вся логика ассистента, данные, AI и синхронизация лежат в `:core`, чистом Kotlin/JVM без Android. Будущий Windows-клиент (Compose Desktop на JVM) подключит `:core` целиком. Ему останется реализовать только UI, микрофон и динамик, хранилище секретов и планировщик. Серверная схема одна для всех клиентов.

**Как проходит команда:**

1. Распознаётся речь (или вводится текст).
2. Из фразы удаляется обращение «Лоли».
3. Если ожидается «да/нет» или выбор варианта, ответ обрабатывается локально.
4. Подбираются кандидаты: записи, похожие на запрос, фокус разговора и недавние записи. Каждый получает метку `#N`.
5. Модель получает промпт с датой, памятью о пользователе и кандидатами. Ответить она должна строго JSON: `{"reply", "actions":[...], "expect_followup", "topic"}`.
6. `ActionParser` проверяет типы, диапазоны, даты и метки: сослаться на запись, которую модели не показывали, нельзя. Некорректные действия отбрасываются, а причина сообщается пользователю.
7. `ActionExecutor` выполняет действия. Удаление ставится в ожидание подтверждения. Неоднозначная ссылка превращается в уточняющий вопрос.
8. Ответы на запросы (суммы расходов, списки) формирует приложение по реальным данным, а не AI. Так модель не может «придумать» цифры.
9. Если AI недоступен (нет сети или ключа, ошибка), та же фраза идёт в `LocalCommandParser`.

## Стек и технические решения

| Компонент | Выбор | Почему |
|---|---|---|
| Язык | Kotlin 2.2 | Современный стандарт Android; тот же язык подойдёт для Windows-клиента на JVM. |
| UI | Jetpack Compose + Material 3 | Декларативный UI, актуальный стек. |
| Архитектура | Модули `:core` (JVM) и `:app` (Android), ручной DI (`AppContainer`) | Ядро тестируется без эмулятора и переиспользуется на Windows. Без Hilt/KSP проще сборка и меньше «магии». |
| Локальная БД | **SQLDelight 2** + **SQLCipher** | Вместо Room выбран SQLDelight: та же схема и запросы работают на JVM (тесты, Windows) и Android. SQLCipher шифрует файл БД. |
| Сеть | Ktor Client (OkHttp на Android) | Один HTTP-слой для Supabase и всех AI-провайдеров. Тесты используют MockEngine. |
| Backend | Supabase: PostgreSQL + RLS + Auth | Требование промта. Схема не привязана к Android. |
| Auth | Supabase Auth (GoTrue REST) | Пароли не хранятся; хранится только сессия, в зашифрованном виде. |
| Фоновая синхронизация | WorkManager | Работает только при наличии сети, с экспоненциальными повторами. |
| Напоминания | AlarmManager (exact при наличии разрешения) + уведомления | Нативный механизм. После перезагрузки напоминания планируются заново. |
| STT | Android `SpeechRecognizer` (основной) + **Vosk** (офлайн) | Системный распознаватель точнее. Vosk работает без Google и без сети. |
| TTS | Android `TextToSpeech` | Стабильный, не требует ключей, поддерживает русский. |
| Wake word | Vosk + нечёткое фонетическое сравнение | Поддерживает любое имя, работает на устройстве. Причины — в разделе [«Голос и wake word»](#голос-и-wake-word). |
| AI | Абстракция `AIProvider`; OpenAI-совместимый провайдер + Anthropic | Один OpenAI-совместимый провайдер покрывает OpenAI, Gemini, OpenRouter, Ollama и LM Studio. Anthropic — отдельный провайдер (Messages API), для проверки расширяемости. |
| Эмбеддинги | `EmbeddingProvider` (OpenAI, Gemini); кэш векторов в локальной БД | Поиск по смыслу работает локально. |
| pgvector | Рассмотрен, в MVP **не используется** | Объём личных данных небольшой, поэтому косинусная близость на устройстве достаточно быстрая и работает офлайн. Серверный pgvector понадобится для Windows-клиента и больших архивов (см. Roadmap). |
| Секреты | Android Keystore (AES-256-GCM) | `EncryptedSharedPreferences` устарел; собственная тонкая обёртка над Keystore прозрачнее. |

Anthropic и остальные провайдеры реализованы напрямую через HTTP (Ktor), без официальных SDK. Так у всех провайдеров одинаковый транспорт, одинаковая маскировка секретов в логах и одинаковые тесты, а APK не тянет тяжёлые зависимости.

## Supabase: настройка

1. Создайте проект на [supabase.com](https://supabase.com) → **New project**. Регион выбирайте поближе.
2. Примените схему. Откройте **SQL Editor** → **New query**, вставьте содержимое файла [`supabase/migrations/20260925000000_loli_init.sql`](supabase/migrations/20260925000000_loli_init.sql) и нажмите **Run**. Либо через Supabase CLI: `supabase link --project-ref <ref> && supabase db push`.
   Миграция идемпотентна (её можно запускать повторно). Она создаёт таблицы, индексы, триггеры и RLS-политики.
3. Настройте авторизацию: **Authentication → Providers → Email** должен быть включён.
   - С **Confirm email** пользователь после регистрации получит письмо и войдёт после подтверждения. Приложение это поддерживает.
   - Для первых тестов подтверждение можно выключить: тогда вход произойдёт сразу после регистрации.
   - В **Authentication → URL Configuration** можно оставить значения по умолчанию: ссылка из письма подтверждает адрес в браузере, после чего вход выполняется в приложении.
4. Возьмите ключи в **Project Settings → API**:
   - `Project URL` → `SUPABASE_URL`;
   - `anon public` (или новый `publishable`) key → `SUPABASE_ANON_KEY`.
   - **Никогда** не используйте `service_role` / `secret` key в приложении или в GitHub Secrets этого проекта.
5. Проверка: в **Table Editor** у каждой таблицы должен стоять значок **RLS enabled**.

**Как устроена схема.** У каждой строки есть `user_id` со значением по умолчанию `auth.uid()`. Политики разрешают `select/insert/update/delete` только владельцу; роль `anon` не имеет доступа вообще. Триггер `loli_sync_guard`:

- игнорирует устаревшие обновления (last-write-wins по `updated_at`);
- запрещает менять владельца строки;
- проставляет `server_updated_at` — это курсор синхронизации.

Удаление мягкое (`deleted = true`), чтобы оно дошло до других устройств. Таблица `profiles` хранит имя ассистента и выбор AI-провайдера и модели. **API-ключи на сервер не попадают.**

Без Supabase приложение тоже работает: кнопка «Продолжить без аккаунта». Свой сервер можно указать и в самом приложении: Настройки → «Свой сервер Supabase».

## Сборка через GitHub Actions

Ничего настраивать локально не нужно.

- **Android CI** (`.github/workflows/android.yml`) запускается при каждом push и pull request. Его можно запустить и вручную: Actions → Android CI → Run workflow.
  1. `core`: 167 тестов ядра (намерения, расходы, заметки, поиск, задачи, напоминания, синхронизация, авторизация, AI-провайдеры, отсутствие сети).
  2. `supabase`: применяет миграции к PostgreSQL 16 и прогоняет тесты RLS и серверной логики синхронизации.
  3. `android`: скачивает офлайн-модель речи (`scripts/fetch-vosk-model.sh`, кэшируется), Android Lint, unit-тесты, сборка debug- и release-APK со встроенной моделью, загрузка APK в **Artifacts**.
- **Release APK** (`.github/workflows/release.yml`) запускается вручную (Actions → Release APK → Run workflow, указать версию) или push'ем тега `v1.0.0`. Он прогоняет тесты, собирает подписанный APK и публикует его в **GitHub Releases**.

> Artifacts расходуют квоту хранилища Actions; у приватных репозиториев она небольшая. Если квота исчерпана, CI не падает, а выводит предупреждение. Тогда скачивайте APK из **Releases** (они квоту artifacts не тратят) или удалите старые артефакты: Settings → Actions → Storage.

Локальная сборка (необязательно): нужны JDK 17+ и Android SDK. Команды: `./gradlew :core:test` и `./gradlew :app:assembleDebug`. Ядро собирается и тестируется даже без Android SDK: `./gradlew -Ploli.skipAndroid=true :core:test`.

## Настройка AI

**По умолчанию облачный AI выключен** — всё работает локально. Включать его необязательно.
Откройте в приложении **Настройки → AI-провайдеры**.

1. Включите «Облачный AI».
2. Включите **один или несколько** провайдеров и введите для каждого свой API-ключ:

В облачный профиль (Supabase) синхронизируются имя ассистента и основной провайдер с моделью; ключи — никогда.

## Голос и wake word

Лоли можно вызвать четырьмя способами (от самого экономного к постоянному прослушиванию):

1. **Кнопка микрофона** на главном экране или тап по сфере.
2. **Жест ассистента.** Настройки → «Сделать ассистентом по умолчанию» → выбрать «Лоли» в пункте «Цифровой ассистент» (у Xiaomi/Samsung — «Помощник и голосовой ввод» / «Приложение-помощник»). Долгое нажатие «Домой» или кнопки питания откроет окно Лоли поверх текущего приложения. Для этого приложение реализует системные `VoiceInteractionService`, сессию и `RecognitionService` (офлайн-распознавание на Vosk) — официальный механизм Android, батарею не расходует.

   **Если Лоли нет в списке.** Некоторые прошивки (realme, OPPO, OnePlus, Xiaomi и др.) показывают в «Цифровом помощнике» только одобренные производителем приложения. Тогда Лоли назначает себя сама:
   - **Shizuku, без компьютера.** Установите Shizuku и запустите его через «Отладку по Wi-Fi». Затем в Лоли: «Сделать ассистентом» → «Настроить автоматически». Лоли выполнит `cmd role add-role-holder android.app.role.ASSISTANT ai.loli.app`, выдаст себе `WRITE_SECURE_SETTINGS`, включит свою службу спецвозможностей (кнопки громкости) и работу поверх приложений.
   - **С компьютера.** Один раз выполните `adb shell cmd role add-role-holder android.app.role.ASSISTANT ai.loli.app` и `adb shell pm grant ai.loli.app android.permission.WRITE_SECURE_SETTINGS`. В приложении есть кнопка «Скопировать команды».
3. **Плитка «Спросить Лоли»** в быстрых настройках (открывает то же окно) и **ярлык** на иконке приложения.
4. **Фоновый wake word «Лоли, …».** Настройки → Голос → «Слушать „Лоли“ в фоне». Офлайн-модель уже встроена в приложение.

**Распознавание речи** (Настройки → Голос): «Автоматически» (по умолчанию), «Системное (Google)» или «Офлайн (Vosk)». В автоматическом режиме Лоли перебирает установленные сервисы распознавания (сначала Google — на многих телефонах по умолчанию выбран сервис производителя, который плохо понимает русский), при сбое переходит на встроенный Vosk, а если не работает ничего — открывает системное окно распознавания Google.

**Почему wake word устроен так.** Мы изучили ограничения Android 11–15:

- Системный «аппаратный» hotword (`HotwordDetectionService` / `AlwaysOnHotwordDetector`) доступен только предустановленным (привилегированным) ассистентам. Стороннему приложению он недоступен.
- Постоянный доступ к микрофону в фоне разрешён только через **foreground service типа `microphone`** с постоянным уведомлением. На Android 14+ такой сервис можно запустить только пока приложение на экране; из фона и после перезагрузки — нельзя.
- Непрерывно гонять Google-распознаватель по кругу ненадёжно: он пищит, ограничен по частоте и отправлял бы всё подряд в облако.

Поэтому выбран Vosk — офлайн-распознавание прямо на устройстве:

- звук не покидает телефон до момента, когда прозвучало имя;
- имя можно поменять на любое («Джарвис», «Кира»…);
- фраза «Лоли, запиши расход 500 рублей» обрабатывается целиком;
- если сказать только «Лоли» и сделать паузу, прозвучит сигнал, и следующая фраза станет командой;
- в диалоговом режиме Лоли слушает продолжение без повторного имени.

После перезагрузки Лоли показывает уведомление «нажмите, чтобы снова включить прослушивание»: так требует Android.

## Безопасность

- **Секреты не хранятся в Git.** Ключи Supabase передаются только через GitHub Secrets/Variables на этапе сборки (`BuildConfig`). Keystore и `local.properties` добавлены в `.gitignore`.
- **API-ключи AI** шифруются AES-256-GCM ключом Android Keystore. Они не синхронизируются и не выводятся в UI.
- **Токены Supabase** (сессия) хранятся так же, зашифрованными. Пароли приложение не хранит.
- **Локальная БД** зашифрована SQLCipher. Пароль — случайные 256 бит под защитой Keystore. `allowBackup=false`: база и секреты не попадают в облачные резервные копии Android.
- **RLS** включён на всех таблицах и покрыт тестами. Покрыто: изоляция пользователей, запрет подмены владельца, запрет перезаписи чужой строки через upsert, отсутствие доступа у `anon`.
- **Логи** проходят через `Redactor`: ключи `sk-…`, `AIza…`, JWT, `Bearer`, пароли и токены маскируются. Тексты команд пользователя в логи не пишутся. В release-сборке пишутся только предупреждения и ошибки.
- **Голос.** В фоне распознавание идёт на устройстве. В облачный AI уходит только текст команды. Системное распознавание (Google) работает по правилам системного сервиса.
- **Незашифрованный HTTP** для AI разрешён только для адресов локальной сети.
- **Действия AI проверяются.** Запись нельзя удалить без подтверждения. Модель может ссылаться только на записи, которые ей показали. Данные в БД дополнительно проверяются `CHECK`-ограничениями.

## Ограничения

**Android и фоновая работа:**

- Фоновое прослушивание требует постоянного уведомления и расходует батарею (порядка нескольких процентов в час, зависит от устройства). Агрессивные оптимизаторы прошивок (MIUI, EMUI и др.) могут остановить сервис. Добавьте Лоли в исключения энергосбережения.
- После перезагрузки фоновое прослушивание нужно включить одним нажатием: Android 14+ запрещает автозапуск микрофона.
- Без разрешения на точные будильники напоминание может сработать с задержкой до нескольких минут (режим Doze).
- Одно и то же напоминание сработает на всех устройствах пользователя, где установлено приложение.

**Распознавание и синтез речи:**

- Системный распознаватель без интернета работает только при установленном офлайн-пакете русского языка (Google). Без него Лоли автоматически использует встроенный Vosk.
- Встроенная модель увеличивает размер APK примерно на 40 МБ; при первом использовании она распаковывается во внутреннюю память (несколько секунд).
- Качество Vosk (малая модель) ниже облачного. Имя ассистента, которого нет в словаре модели (например, «Лоли»), распознаётся нечётко; возможны редкие ложные срабатывания или пропуски. Самый надёжный вариант — «Лоли» → сигнал → команда.
- Голос TTS зависит от установленного на телефоне синтезатора. Если русского голоса нет, Android предложит его скачать.

**Локальное понимание речи:**

- Оно основано на правилах и словарях русского языка и понимает очень много формулировок (см. тесты `LocalNluTest`, `LocalModeEngineTest`, `RegressionTest`), но не «любую» речь, как большая языковая модель. Непонятую фразу ассистент предложит сохранить заметкой.

**AI (если включён):**

- Для свободного разговора нужен интернет и API-ключ.
- Расходы по API оплачивает владелец ключа. По умолчанию выбраны модели с разумным соотношением цены и качества; модель можно поменять.
- Модель может ошибиться с намерением. Критичные операции всё равно проходят валидацию и подтверждение.
- Семантический поиск по эмбеддингам доступен у OpenAI и Gemini. Для Anthropic и локальных моделей — лексический поиск с синонимами.

**Синхронизация:**

- Конфликты простых записей решаются по принципу last-write-wins по времени устройства. Если часы на устройствах сильно расходятся, возможен неверный выбор версии. Тексты заметок при конфликте объединяются без потерь.
- Эмбеддинги не синхронизируются: каждый клиент пересчитывает их сам.
- Выход из аккаунта удаляет данные с устройства. Несинхронизированные изменения сначала отправляются; без сети приложение предупредит.

**Сборка и обновления:**

- Постоянный ключ подписи создаётся в CI автоматически и хранится в кэше GitHub Actions (`scripts/signing-key.sh`). GitHub удаляет кэш, если им не пользовались 7 дней; тогда будет создан новый ключ и обновление потребует один раз переустановить приложение. Чтобы ключ был вечным, сохраните его в секрет `LOLI_KEYSTORE_BASE64` (+ `LOLI_KEYSTORE_PASSWORD`, `LOLI_KEY_ALIAS`, `LOLI_KEY_PASSWORD`).
- Автообновление читает GitHub Releases без токена — репозиторий должен быть публичным (секретов в нём нет).
- При переходе на новый ключ подписи Android не даст обновить приложение поверх — Лоли сообщит об этом, нужно один раз переустановить.

## Roadmap

- **Windows-клиент** на Compose Desktop с переиспользованием `:core`: та же учётная запись, память, AI-конфигурация. Wake word — через Vosk для Windows.
- Вход через **Google и другие OAuth** (Supabase Auth, PKCE). `AuthManager` уже изолирует этот слой.
- Серверный семантический поиск на **pgvector** (общий индекс для всех клиентов).
- Потоковые ответы AI и более быстрый голос. Выбор голоса TTS.
- Английский и другие языки: провайдеры STT/TTS уже принимают язык параметром.
- Локальные AI-модели на устройстве.
- Календарь, контакты, почта, Telegram, умный дом, файлы — как новые типы действий `AssistantAction`.
- Персональные автоматизации («каждый вечер присылай сводку расходов»), краткое резюме памяти по расписанию.
- Realtime-синхронизация (Supabase Realtime) вместо периодического опроса.
- Инструментальные UI-тесты на эмуляторе в CI.
